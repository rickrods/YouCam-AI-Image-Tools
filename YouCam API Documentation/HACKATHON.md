## Judging Criteria

**Technological Implementation:**
- How thoroughly and skillfully does the project integrate at least one YouCam API? Does the project demonstrate clear consumer or retail value?
- Does the code reflect genuine effort and a working, non-trivial implementation?

**Design:**
- Does the project deliver a complete, coherent product experience — not just a technical proof of concept?

**Potential Impact:**
- Does the project make a credible, specific case for solving a real problem for a real audience?
- Does the solution actually address that problem based on what's demonstrated?

**Quality of Idea:**
- Is this a creative, non-obvious use of at least one YouCam API?
- Does the team demonstrate genuine understanding of the problem space they're working in?
